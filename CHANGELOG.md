# Changelog

Versions follow [Semantic Versioning](https://semver.org/). Releases are tagged `vX.Y.Z`.

## 0.1.0 - 2026-11-02

First tagged release.

- Interactive 3D atlas of nine petrol/electric pairs from Volkswagen, BMW, Mercedes-Benz, Audi, Fiat, MINI and Hyundai, all with real 3D models.
- Click any of ~45 parts per car for a "what it is / how it works" explanation.
- Guided "How it works" tours, animated explainers, Run mode, Mechanic (bonnet) view, Exploded view, X-ray and Differences.
- Screenshots in `docs/screenshots`.
